# 🚀 Albin's Portfolio Website

Welcome to the repository for my personal portfolio website! This project is a modern, responsive, and clean static portfolio built from scratch using vanilla web technologies. It is optimized for performance, clean navigation, and custom domain deployment.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and content organization.
* **CSS3:** Custom layouts, responsive design, and global typography.
* **JavaScript (ES6+):** Dynamic client-side behavior and interactions.
* **GitHub Pages:** Fast, secure, and reliable static hosting.

---

## 📁 Repository Structure

```text
├── about/              # Profile page and personal background
├── fonts/              # Custom web typography assets
├── images/             # Central media store for icons, graphics, and screenshots
├── projects/           # Portfolio showcase for featured development work
├── CNAME               # Custom domain configuration for GitHub Pages
├── index.html          # Main landing/home page
├── README.md           # Project documentation and overview
├── script.js           # Core JavaScript logic and animations
└── style.css           # Global stylesheet and responsive rules
```

---

## ✨ Features & Optimizations

* **Clean URL Routing:** Organized directory structures allow for extension-free navigation (e.g., `://domain.com` instead of `about.html`).
* **Fluid Responsiveness:** Built using a mobile-first design approach to look great across desktops, tablets, and smartphones.
* **Modular Styling:** Centralized global layout utilizing custom CSS properties for easy theme modifications.
* **Fast Performance:** Pure vanilla implementation ensuring rapid page load speeds with zero external framework overhead.

## 🚀 Local Setup & Deployment

### Run Locally
To clone and run this project on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Noob0639/albin_website.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd albin_website
   ```
3. **Open the project:**
   Open `index.html` directly in your browser, or serve it using an extension like *Live Server* in VS Code.

### Deployment Note
This repository is configured to auto-deploy to **GitHub Pages** via the `main` branch. Custom domain configurations are actively mapped through the `CNAME` file.
