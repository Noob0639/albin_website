# Albin's Portfolio Website

Welcome to my personal website repository! This is a clean, static portfolio built with vanilla HTML, CSS, and JavaScript.

## 🚀 Features
- **Clean URLs:** Optimized directory structure for extensions-free navigation.
- **Responsive Design:** Styled with a centralized, global layout.
- **Custom Domain:** Configured using GitHub Pages and a custom CNAME setup.

## 📁 Structure Overview
- `/about` - About me profile page
- `/projects` - Portfolio showcase directory
- `/images` - Central asset store for media files
